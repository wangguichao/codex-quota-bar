# Maintenance notes

This repository contains the clean public source for Codex Quota Bar, a Windows WPF overlay.

- Read README.md, docs/share/使用说明.txt and docs/VALIDATION.md before changes.
- Use official Codex App Server account and rate-limit data; do not estimate plan quota from token counts.
- Keep account/workspace confirmation explicit and recheck identity before saving bindings.
- Do not read, commit or distribute credential files, personal bindings, settings, diagnostics or chat content.
- Mark simulated data and tests clearly. Do not claim physical mouse, multiple monitors or long-run acceptance from simulated checks.
- Keep the overlay from stealing focus. Dispose timers, hooks, tray icons and owned query processes on exit.
- Put executable/runtime bundles in GitHub Releases, not Git history.
- Check behavior with appropriate tests and review changes before publication.
