Codex额度条 0.5.0 朋友使用说明
===============================

适用：Windows x64 电脑，官方 Codex 桌面端，ChatGPT 账号的个人空间。
这是一个独立的小工具，并非 OpenAI 官方客户端。仅显示 Codex 套餐额度；不显示普通 ChatGPT 聊天剩余次数或 API 余额。
Windows 11 x64 为建议环境；本机测试环境为 Windows 10 Pro 22H2、单屏125%。Mac、Windows ARM和公司/团队空间未验证。

第一次使用（约3步）
------------------
1. 把整个压缩包“全部解压”到一个固定文件夹，例如“文档\Codex额度条”。不要直接在压缩包里打开，也不要只取出一个exe。
   先打开官方 Codex 桌面端，登录你自己的账号，并在账号菜单确认当前是“个人空间”。
   如果还没有官方桌面端，从官方页面安装：https://learn.chatgpt.com/docs/windows

2. 双击文件夹内的“启动.cmd”。
   首次打开会显示“用你自己的账号连接”。点击“检查连接”。
   如果提示尚未登录，点击“登录自己的账号”，在自动打开的官方浏览器页面完成登录。
   登录时可能同时出现官方命令行窗口，请保持它打开直到登录结束，再回到额度条点“检查连接”。
   不需要额外安装.NET、Node.js、Python、PowerShell 7或开发工具；连接组件和运行环境已在包内。

3. 检查界面中的“连接账号”及额度周期、重置时间。
   打开 Codex 桌面端的账号菜单，将其中的登录邮箱填入额度条。
   确认桌面是同一账号的个人空间，额度周期、重置时间也与这里一致，勾选核对框。
   点击“确认并开始使用”。保存前程序还会再次检查账号；若期间账号改变，会要求重新核对。
   没有对应周期或无法确认时，先不要确认；不能只因百分比接近就认定账号相同。

以后使用
--------
双击“启动.cmd”即可。第一次绑定后无需每次重新登录。
如果程序已在托盘运行，再次双击会恢复原窗口，不会重复开出第二条。
账号绑定与显示设置保存在当前 Windows 用户的：
%LOCALAPPDATA%\CodexQuotaBar
不要将这个个人数据文件夹作为分享包发送给别人。原始压缩包不包含任何人的账号绑定或登录信息。

拖动、隐藏与托盘
--------------
- 按住额度横条鼠标左键，在 Codex 窗口范围内拖动；松开后位置自动保存。
- 勾选“锁定位置（鼠标穿透）”，横条固定，鼠标可以操作下方 Codex 界面；取消勾选可继续拖动。
- “重置位置”恢复顶部居中；可调整宽度、主题、刷新间隔和显示周期。
- 切到其他应用时横条会隐藏；回到 Codex 后显示。
- 点击窗口的最小化按钮或“最小化到托盘”，控制窗口会收起，额度继续自动更新。
- 双击任务栏右下角绿色 Q 图标恢复；图标可能在“显示隐藏图标”的小箭头里。
- 右键托盘图标可恢复、显隐横条、锁定/解锁、重置位置或退出。
- 关闭控制窗口或托盘选“退出”会结束程序。最小化会继续运行，关闭会退出。

切换账号或工作区
----------------
换号后在控制窗口点“重新核对账号”，按第一次使用步骤重新检查和确认。
登录由官方 Codex 管理；如果电脑原来就安装了 Codex CLI/扩展，可能使用其已有登录。
确认前请核对桌面账号；本工具无法自动证明桌面独立换号后的身份。
当前只支持个人空间，公司/团队空间请勿绑定为个人空间。

常见问题
--------
看不到横条：
  确认官方 Codex 窗口在前台；在控制窗口点“显示横条”“重置位置”。
不能拖动：
  取消“锁定位置（鼠标穿透）”。横条的拖动范围是 Codex 窗口以内。
显示账号待核对：
  点“重新核对账号”；使用和桌面端相同的 ChatGPT 账号，核对个人空间。
显示需要登录/读取失败：
  重新核对时点击登录自己的账号，完成官方登录；确认网络正常，再检查连接。
  登录流程使用浏览器；不要把账号密码、令牌或登录缓存发给软件发送者。
显示过期：
  上次成功更新超过180秒后会隐藏旧数值；可点“立即刷新”，网络恢复后自动重试。
找不到连接组件：
  检查是否完整解压，app\runtime\codex.exe 是否仍在。重新解压原包到新文件夹。
移动了程序文件夹：
  如旧绑定的组件位置失效，按引导重新检查；无需手动编辑配置。
首次启动没有引导：
  本机可能已有这个工具的个人配置，点“重新核对账号”检查。
程序完全无法打开：
  确认是Windows x64，文件已全部解压且app子文件夹完整。把报错内容告知发送者。

包内文件
--------
启动.cmd          日常打开入口
使用说明.html     可直接用浏览器打开的排版版说明
使用说明.txt      本说明
app               主程序、自带.NET运行环境、官方Codex CLI连接组件
源码.zip          干净源码和构建脚本；普通使用无需解压
组件与许可        官方Codex CLI及.NET运行时的许可和通知
版本信息.json     版本、组件信息和文件校验值

不要单独移动app中的文件。软件没有设置开机启动；不用时退出即可。
本包为0.5.0朋友分享版，不包含发送者的身份绑定、显示偏好、诊断快照、聊天内容或登录凭据。
登录和网络服务仍需你自己的账号及可用网络。首次引导与模拟账号的成功/失败路径已测试；没有代替朋友完成实际登录。
目前实机鼠标连续操作、跨屏/其他真实DPI、真实休眠/断网、8小时运行仍待进一步验证。
